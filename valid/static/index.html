VALID Version-Aware Lookup In DITA

Ask about Cloud TPU. Answers come only from the documentation for the generation you mean, and every answer shows its reasoning. New here?

Help

Quick start

  1. Type a Cloud TPU question and name the generation: v5e, v5p, v6e (Trillium) or TPU7x (Ironwood).
  2. Press Ask (or Ctrl/Cmd+Enter). Or click an example question to try it.
  3. Read the answer, open its Source link, and open How VALID got here to see the reasoning.

VALID answers only from the documentation for the generation you mean. If the documentation does not say, it tells you instead of guessing.

Naming a generation

  • Say it: "On v6e, ...". Aliases work too: Trillium means v6e, Ironwood means TPU7x.
  • A machine type that belongs to one generation also counts, for example ct5p-hightpu-4t (v5p).
  • To compare, name both: "Compare chips per host for v5p and TPU v6e".
  • If you name none, VALID asks which one you mean. It never guesses. A bare "v5" is treated as none, because it could be v5e or v5p.
  • Questions are limited to 400 characters, and each one stands alone: VALID does not remember the previous question.

Reading an answer

  • Badges: "Answered" and a "Checked" count: how many citations were in scope and how many values matched the cited text.
  • Steps: one per generation, each with a Source link to the exact documentation line.
  • Not documented: a yellow-edged note means the documentation answers some of your question, not all of it. It is part of the answer.
  • Excluded on purpose: the generations VALID did not search, so their content could not leak in.

When VALID declines

"Declined, by design" means the documentation for your generation does not support an answer, and VALID would rather say so than guess. It happens when nothing is close enough, when the retrieved passages do not contain the answer, or when a draft failed its checks twice. Try the generation you meant, reword using the documentation's terms, or ask about a different generation.

The reasoning panel

  • Decide the scope: which generation and which words in your question set it. No AI model decides this.
  • Search inside the scope: the filter applied before any search, the best distance (VALID declines above 0.40), and the passages found. Meaning rank is closeness in meaning (lower distance is closer), keyword rank is word matching, fused combines the two.
  • Gemini call: which model drafted the answer and which were tried first. "Skipped" means a busy model is resting for a few minutes.
  • Check the answer: plain code confirms every citation is in scope and every command, number and identifier appears in the passage it cites.

Limits and problems

  • Speed: 2 to 3 seconds when the model is quiet, up to about 35 seconds when it is busy (free tier).
  • Daily limit: 50 questions a day shared by everyone, resetting at 00:00 UTC. Choosing a generation or a busy model does not use one.
  • "Model busy": press Try again, or wait a minute.
  • "Access code missing or wrong": re-enter the code, or reopen your invitation link. Too many wrong codes locks you out for 15 minutes.
  • Coverage: a small, curated documentation set for four generations. For anything important, follow the Source link: the checks verify values against the cited text, not whether the documentation itself is right.
