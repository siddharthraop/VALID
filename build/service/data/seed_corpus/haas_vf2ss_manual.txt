HAAS VF-2SS SERVICE MANUAL
Section 18: Spindle Maintenance and Fault Codes

18.1 Overview
The VF-2SS spindle assembly requires periodic bearing inspection and re-seating
per the maintenance schedule in Section 4. This section covers spindle-related
fault codes and the corrective procedures for each.

18.2 Fault Code E-01: Spindle Overtemp
If fault E-01 appears, halt the spindle immediately and allow a 30-minute
cooldown period before inspection. Check coolant flow at the spindle nose.

18.3 Fault Code E-02: Spindle Encoder Fault
Fault E-02 indicates an encoder signal loss. Re-seat the encoder cable at
connector J14. If the fault persists, replace the encoder assembly.

18.4 Fault Code E-04: Spindle Bearing Noise / Intermittent Fault
Fault E-04 indicates spindle bearing wear or improper seating following a
prior service event. Procedure:
  Step 1: Stop the spindle and lock out per Section 22 (Lockout/Tagout).
  Step 2: Remove the spindle nose cover (4x M6 bolts).
  Step 3: Inspect the front bearing race for pitting or discoloration.
  Step 4: If re-seating the bearing, torque the retaining nut to 45 Nm.
          Do not exceed 45 Nm. Under-torquing below 40 Nm has been linked
          to bearing migration under load and fault recurrence.
  Step 5: Reinstall the nose cover and torque bolts to 8 Nm in a cross pattern.
  Step 6: Clear the fault code and run a 5-minute no-load spindle test before
          returning the machine to production.
This procedure is documented at page 247 of the full OEM service manual.

18.5 Fault Code F-12: CMM Probe Fault
Fault F-12 on the CMM indicates a probe calibration drift. Recalibrate
against the reference sphere before resuming measurement operations.
